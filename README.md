# Адвент уставшего котика

Статический сайт: 24 зимних удовольствия, три равноценных варианта на каждый день.

## GitHub Pages
Распакуйте архив. Загрузите index.html и .nojekyll в корень репозитория.
В Settings → Pages выберите Deploy from a branch → main → /(root).
Можно открыть index.html прямо на компьютере; зависимости и сборка не нужны.

## Поведение
Каждый год с 1 по 24 декабря карточки открываются в 00:01 по времени устройства.
После 24 декабря все карточки доступны до конца года. С января отсчёт до нового декабря.
Отметки хранятся в localStorage этого браузера, отдельно по годам и отдельно от предыдущего адвента. Если браузер запрещает хранение, отметки могут не сохраниться. Синхронизации нет.
Предпросмотр всех дней: ?demo=2026-12-24T12:00. Его отметки отдельные.
Для проверки границы: ?demo=2026-12-01T00:00 и ?demo=2026-12-01T00:01.
Список TASKS находится внутри index.html. Будущие задания скрыты интерфейсом, но доступны в исходнике.
Нет аккаунтов, аналитики, внешних шрифтов, серверов и платных зависимостей.

## Кошачьи анимации
Закрытые дни показывают спящего котика. У каждого из 24 дней — своя анимация при первом показе карточки (включая автоматически открытую карточку дня). История сохраняется отдельно по годам и для деморежима. Звука нет. Escape или «Пропустить» закрывает анимацию. При системной настройке уменьшения движения показывается короткая статичная композиция. «Сбросить весь статус» очищает отметки и историю анимаций после подтверждения; даты открытия не меняются.

В каждой карточке под заданием — отдельное мягко-ироничное напоминание котика. Оно также включается в текст «Поделиться заданием».

Закрытые карточки: 24 сочетания шести поз и шести расцветок котиков; рисунки встроены в HTML как SVG.
